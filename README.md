## 🛠️ Requirements

You can practise the examples using:

* Python 3
* Visual Studio Code
* PyCharm
* Jupyter Notebook
* Any Python-compatible online editor

## 🚀 How to Use

1. Install Python 3 on your computer.
2. Open or download the PDF document.
3. Read the explanation for each topic.
4. Create a Python file ending with `.py`.
5. Write and run the provided examples.
6. Compare your results with the expected outputs.
7. Complete the practice assignments independently.

## ▶️ Run Python Code

Open the terminal inside your project folder and run:

```bash
python app.py
```

On some computers, use:

```bash
python3 app.py
```
